Covers: Before you write code

A project keeps its specifications beside its code, each with numbered acceptance criteria
and a table naming the test behind each one.

A user has asked for a new behaviour: when a run finishes, the desk should show how long it
took. Nothing in the specs mentions this today.

Say what you would do, in order, before writing any implementation code. Do not write the
code. Do not edit any file — describe what you would change and why.
